# Reply Action Skill Bindings

## Confirmed Need

Bricks should eventually support reply action buttons that invoke reusable skills against an existing assistant reply.

## Example Use Cases

- Rewrite a single reply with a different expression style.
- Generate a derived reply without changing the channel output tone setting.
- Offer an explicit action to promote a reply style into the channel output tone later.

## Notes

- This is not part of the current output tone and input grammar fixer scope.
- Reply actions should reuse the standard skill layer through a reply-level binding.
